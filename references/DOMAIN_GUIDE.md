# 教育机构AI使用政策制定领域指南

## 业务问题

教师和员工已在使用AI备课、批改、营销和客服，但机构缺少允许范围、核验责任、数据和工具边界。

## 产品解决方案

结合业务场景与平台规则制定AI使用政策、审批流程、人工核验、数据分级和违规处理。

## 输入质量要求

| 字段 | 名称 | 必填 | 质量要求 |
|---|---|---|---|
| `organization_profile` | 机构概况 | 是 | 业务、角色和用户群 |
| `ai_tools` | 现有AI工具 | 是 | 名称、用途、数据输入和输出 |
| `use_cases` | AI使用场景 | 是 | 备课、教研、营销、客服等 |
| `data_categories` | 数据类别 | 是 | 学生、家长、教师和经营信息 |
| `student_contact` | 学生接触方式 | 是 | 是否直接互动及年龄范围 |
| `current_policies` | 现有制度 | 否 | 隐私、采购、内容审核 |
| `approval_roles` | 审批角色 | 是 | 教学、IT、合规和管理 |
| `risk_tolerance` | 可接受风险 | 是 | 由负责人确认，不由模型设定 |

## 证据判断

- 用户原文优先于模型推断。
- 外部政策或公开事实应记录标题、发布机构、发布日期、URL、访问日期和适用范围。
- 无法核验时标记`EVIDENCE_UNVERIFIED`，不补造来源。
- 数据冲突必须并列展示，并说明对结论的影响。

## 人工复核

负责人/教学/IT/法务应确认：AI允许场景、数据输入、人工核验、处罚和例外审批。未经确认的内容只能作为草案。

## 主要风险

政策需法律/安全/业务复核；不可代替具体工具的隐私条款审查；避免模糊禁令导致无法执行。
